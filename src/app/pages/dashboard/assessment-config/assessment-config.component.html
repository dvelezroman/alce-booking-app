Sobre esta configuración

Estos valores forman parte de las reglas académicas utilizadas para el seguimiento de los estudiantes.

Qué controla cada parámetro

Puntaje máximo de evaluación

Define el valor máximo que puede obtener una evaluación.

Puntaje mínimo de aprobación

Establece el valor requerido para considerar aprobada una evaluación.

Días como estudiante nuevo

Determina durante cuánto tiempo se identifica al estudiante como nuevo.

Horas mínimas por semana

Indican la carga mínima de clases recomendada para el estudiante cada semana.

Importante

Verifica los valores antes de modificarlos, ya que pueden afectar procesos académicos existentes.
